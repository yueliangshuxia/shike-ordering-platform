食刻点餐 · 演示版（需要 Java 21）

1. 先把整个压缩包解压出来，不要在压缩包里直接双击。
2. 双击 run.bat。
3. 浏览器会自动打开 http://127.0.0.1:8080/
   - 需要电脑已安装 Java 21
   - 不需要 MySQL（数据库是内嵌的 H2）
   - 第一次启动要 10-20 秒，页面没出来就刷新一下

演示账号：
  顾客   13800000621 / 123456
  管理员 13900000001 / admin123
  后厨   13900000002 / kitchen123

数据保存在 data/ 文件夹。删掉 data/ 再启动，就恢复成初始演示数据。

8080 端口被占用时，可以这样换端口：
  java -jar shike-ordering.jar --spring.profiles.active=demo --server.port=8081
然后访问 http://127.0.0.1:8081/

停止服务：关闭标题为 "Shike Service" 的窗口即可。
